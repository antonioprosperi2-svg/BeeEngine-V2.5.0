# Contributing to BeeEngine

Thanks for wanting to help. You do not need to be an expert. A clear bug report or a small fix is already useful.

BeeEngine is vanilla JavaScript with zero runtime dependencies. Please keep it that way: no frameworks, no new packages, and no build step.

## Bugs and ideas

Open a [GitHub issue](https://github.com/antonioprosperi2-svg/BeeEngine-V2.0/issues) before you start a large change.

- For a bug, say what you expected, what happened, and how to see it again.
- For an idea, say what it is for. A short example helps.

## Code changes

1. Fork the repository and clone your fork.
2. Create a branch, for example `fix/bullet-bounds`.
3. Make the change. Match the style of the file you are editing.
4. Open a pull request with a clear description: what changed, and why.

You need Node.js 18 or newer. Check types with `npm run typecheck`. Run a test file with `node scripts/test-<name>.mjs`.

If you are new to pull requests, GitHub's guide [Hello World](https://docs.github.com/en/get-started/quickstart/hello-world) walks through a fork, a branch, and a pull request.
