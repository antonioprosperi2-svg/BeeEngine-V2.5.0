# Security Policy

## Supported versions

Only the latest published version of BeeEngine is supported. Older releases do not get security fixes, so please update to the latest version before reporting a problem.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Contact the maintainer privately through GitHub: [antonioprosperi2-svg](https://github.com/antonioprosperi2-svg). Send a short message asking for a private channel, and share the details there.

Helpful details to include:

- what the problem is and where it happens (core, a plugin, the asset loader, input...)
- the steps to reproduce it, ideally with a small example
- the BeeEngine version and your browser or device

You will get an answer as soon as possible. Please give us time to look before you talk about it in public. Once the issue is fixed, we will publish a new version and credit you if you wish.

Thank you for helping keep BeeEngine and its users safe.
