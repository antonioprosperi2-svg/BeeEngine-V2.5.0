# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Contact the maintainer through GitHub: [antonioprosperi2-svg](https://github.com/antonioprosperi2-svg).

Describe what is affected and how to reproduce it. Please give us time to look before you talk about it in public.

## Supported versions

Only the latest version is supported. Older releases do not get security fixes.
